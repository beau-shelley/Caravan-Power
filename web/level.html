Caravan dimensions & calibration help

Set level: once, on ground you've checked with a spirit level (on the floor inside). The sensor's mounting angle is then cancelled out and remembered.

Learn front: once, after Set level. Wind the jockey up so the front is 2-3 cm high and press it. This tells the hub which way the van faces, so the sensor can be mounted any way round.
