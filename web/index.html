Alert rules

Rules are set up here; the caravan display only shows them. Alerts are pushed to your phone via ntfy (if enabled per rule). An optional action can shed load automatically.

Caravan display

It dims right down when idle. The first touch only wakes it, so you can't press a button by accident.

Allow control from the cloud dashboard
Only changeable on the caravan Wi-Fi or the display.
Cloud connection (this browser)
Stored only in this browser. Use a dashboard-only broker user.
Victron solar controllers (Bluetooth)

In VictronConnect open each SmartSolar → cog → Product info → enable Instant readout via Bluetooth → Instant readout details: Show, and copy the encryption key here. The address is optional; use Find nearby to see what the hub can hear.

Secure mode code

If the van is moved while armed you get 5 minutes to disarm before the full alarm. Disarming on the caravan display needs this code; this phone doesn't.

Caravan level

Bubble level with wheel and jockey heights. Connects to the van over Bluetooth, so it works at sites without internet.

Open level page
Weather location

Use your phone's location or search for a town. (The phone level page also offers this once the van is level.)

Tank calibration

Fill or empty a tank, then press the matching button to store the sender reading.

Temperature sensors

Bluetooth thermometers (ThermoPro TP357, Govee H5075, Shelly BLU H&T, Xiaomi with pvvx firmware) or wired DS18B20 probes. Warm a sensor in your hand to tell which is which.

Battery

The hub works out the battery % and time left itself, by counting the amps in and out against this size. (The BMPRO's own % stops at 600 Ah.) It resets to 100% each time the charger shows the bank is full.

Diesel heater

Bluetooth works with heaters that use the AirHeaterBLE app (the hub uses the same protocol). Close the app on your phone first: the heater takes one Bluetooth connection at a time. Use Find nearby to get its address. The 433 MHz option needs a CC1101 module in the hub box and isn't built yet.


      

      

        
BMPRO OdysseyLink (Bluetooth)

        
Enter the OdysseyLink's Bluetooth address and press Connect; the hub remembers it. With bmproExplorer on, every frame is logged here – switch pumps in the Odyssey app and watch what changes.
